# 🏏 BPL-11 — Assemble Your Ultimate Dream 11 Cricket Team

An interactive and modern web application built for cricket fans to select, manage, and build their ultimate Bangladesh Premier League (BPL) fantasy squad. Developed with **React**, **TypeScript**, and **Tailwind CSS**, the platform features real-time coin management, dynamic player rosters, and an intuitive team selection system.

## 🧩 Main Features

* **Dynamic Player Roster:** Browse marquee international and national players (such as Shakib Al Hasan, Babar Azam, and Rashid Khan) with complete role, country, and pricing metadata.
* **Credit & Balance System:** Features an interactive **"Claim Free Credit"** button allowing users to increase their total coin balance dynamically.
* **Real-time Team Selection:** Seamlessly toggle between **Available** and **Selected** tabs while managing your squad limit and budget.
* **Detailed Player Cards:** Highlights player roles (All-Rounder, Batter, Bowler, Wicket-Keeper), batting/bowling handedness, and market pricing.
* **Fully Responsive UI:** Built with dynamic visual components and clean layout grids optimized across desktop, tablet, and mobile browsers.

---

## 🛠️ Technology Stack

* **React:** Functional component architecture for smooth, fast rendering.
* **TypeScript:** Ensures static type safety across player objects, state, and event handling.
* **Tailwind CSS:** Utility-first framework providing dark dynamic hero cards, customized buttons, and adaptive page structure.
* **JSON Data Source:** Asynchronously feeds player stats, roles, ratings, and valuation prices.

---

## 📦 Dependencies

* **React Icons / Font Awesome:** Crisp SVG icon assets for currency coins, ratings, and navigation links.
